# ai-obsidian — Obsidian 工作流

面向 Codex 的 Obsidian 任务管理、报告、知识库初始化、开源调研与编码会话扫描插件。

## Skill

| Skill | 触发方式 | 说明 |
|------|----------|------|
| **task-hub** | `$ai-obsidian:task-hub` | 统一管理任务、项目、归档和周期报告 |
| **opensource-research** | `$ai-obsidian:opensource-research` | 产出结构一致的中文开源调研报告 |
| **vault-init** | `$ai-obsidian:vault-init` | 初始化 Obsidian 顶级知识库和聚合首页 |
| **session-scan** | `$ai-obsidian:session-scan` | 扫描 Claude Code/Codex/DeepSeek Harness/pi 会话并按项目整理工作证据 |

## 安装

```bash
codex plugin add ai-obsidian@ai-obsidian
```
