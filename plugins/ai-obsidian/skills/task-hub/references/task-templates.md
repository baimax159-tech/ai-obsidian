# 任务骨架模板（照抄式，降偏差）

写操作前先读 `task-format.md` 对齐格式契约；本文件是三种高频结构的**照抄骨架**——复制整段后逐字段替换占位符，减少手写导致的格式偏差（缩进、字段顺序失配）。

所有骨架都从 `## {项目名}` 分区起手：项目归属靠分区，任务行**不带**项目标签。落笔前先按 task-format「项目集合」扫描 `计划中.md` / `已归档.md` 已有的 `## 项目名` 分区——命中即归入该分区，未命中先确认是「新建分区」还是「已有项目的别名/笔误」，不臆造重复分区。

## 占位符约定

- `{...}`：必填，替换为真实值后占位符不得残留。
- `{...?}`：可选，用则替换整行、不用则**删掉整行**。
- 日期一律 `YYYY-MM-DD`；每层缩进 **1 个 Tab**，不用空格。
- 优先级取 `⏫`（最高）/ `🔺`/ `🔼`/ `🔽`（最低）之一，无则删。

---

## 骨架一：叶子任务（无子任务）

写入 `任务/{YYYY}/计划中.md` 对应 `## {项目名}` 分区。

```markdown
## {项目名}

- [ ] {标题} {优先级?} 🛫 {开始日期} 📅 {计划完成日期}
	> {说明?}
```

---

## 骨架二：带子任务的父任务


```markdown
## {项目名}

- [ ] {父任务标题} 🛫 {开始日期} 📅 {计划完成日期}
	> {父任务说明?}
	- [ ] {子任务一} 🛫 {开始日期} 📅 {计划完成日期}
	- [ ] {子任务二} 🛫 {开始日期} 📅 {计划完成日期}
		> {子任务说明?}
```

- 子任务数 ≠ 2 时，按实际数量增删 `- [ ]` 子任务行。

---

## 骨架三：部分归档（父任务未完成，部分子任务已完成）

仅在用户明确触发归档时使用。父任务未完成、部分子任务已完成 → 一棵树拆两侧写。父任务两侧都保留**真实状态**，容器侧不补 `✅`。

### 计划中侧（`计划中.md` 保留父任务 + 未完成子任务）


```markdown
## {项目名}

- [ ] {父任务标题} 🛫 {开始日期} 📅 {计划完成日期}
	- [ ] {未完成子任务} 🛫 {开始日期} 📅 {计划完成日期}
```

### 已归档侧（`已归档.md` 同一父任务作上下文容器，只放已完成子任务）

容器父任务保留真实未完成状态、不补 `✅`。

```markdown
## {项目名}

- [ ] {父任务标题} 🛫 {开始日期} 📅 {计划完成日期}
	- [x] {已完成子任务} 🛫 {开始日期} 📅 {计划完成日期} ✅ {完成日期}
```

- 父任务**已全部完成**时不走本骨架：直接整棵树从 `计划中.md` 移到 `已归档.md`。
- 恢复前先与用户确认恢复范围，再从 `已归档.md` 移回并按要求设置状态。

---

## 旧任务树内新增子任务

仅用于尚未显式迁移的旧父任务，保持该树原有格式；不要用它创建新的顶级任务：

```markdown
	- [ ] {子任务标题} #project/{所在分区项目名} {优先级?} 🛫 {开始日期} 📅 {计划完成日期}
		- {备注?}
```

需要统一格式时转入 `legacy-migration.md`。
