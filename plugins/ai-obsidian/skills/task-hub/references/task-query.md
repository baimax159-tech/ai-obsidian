# 任务查看与筛选

查看是只读操作，不修改任务状态、日期、进度条或文件顺序。

## 数据范围

- 默认读取当前年度 `任务/{YYYY}/计划中.md`。
- 用户要求已完成、历史或归档时，同时读取相关年度 `已归档.md`。
- 指定日期范围跨年时读取涉及的全部年度目录。
- 涉及项目筛选时先收集 `## 项目名`；项目名不匹配时列出现有项目，不创建分区。

## 解析兼容

- 同时识别 task-hub 规范和旧 `work-management` 格式。
- 标题比较前剥离父任务进度条、`#project/项目名`、优先级和日期字段。
- 备注同时读取缩进 blockquote、旧普通列表说明和行尾 `备注：...`。
- 项目以所在 `## 项目名` 为主；旧标签只作为一致性检查，冲突时报告异常但不修改。

## 筛选规则

支持组合条件：

- 项目、父任务或标题关键词；
- `[ ]` 未开始、`[/]` 进行中、`[?]` 阻塞、`[x]` 已完成；
- `🛫` 开始日期、`📅` 计划完成日期、`✅` 完成日期；
- 今天、本周、本月或任意 `YYYY-MM-DD ~ YYYY-MM-DD`；
- 计划中、已归档或两者。

日期范围默认采用区间相交：任务满足 `🛫 <= 范围结束` 且 `📅 >= 范围开始`，或 `✅` 落在范围内，即视为命中。用户明确只查开始、计划完成或实际完成日期时，仅使用对应字段。

## 输出

- 按项目分组，保留父任务及命中的子任务上下文。
- 子任务命中时保留父任务标题；不要把子任务提升成无上下文的顶级条目。
- 默认显示状态、标题、关键日期和必要备注；不输出进度条 HTML 或重复项目标签。
- 没有命中时说明实际扫描的年度、文件和条件，不直接断言任务不存在于其他年份。
