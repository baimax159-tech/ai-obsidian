# task-hub — Obsidian 任务中枢

一个技能管起 Obsidian 任务的**完整生命周期**：创建、查看、修改、归档 / 恢复、格式迁移和生成报告。

## 设计：单一记录源

- **记录**：`任务/{YYYY}/计划中.md`、`已归档.md` —— 纯 Markdown checkbox，人可读可编、模型可读写。
- 创建 / 查看 / 修改 / 归档 / 报告使用同一套解析规则。
- **注释**：任务行尾内联脚注（`^[...]`），渲染为「上标角标」、正文干净；可选装 `任务样式.css` 片段做角标弱化与状态着色。
- 只管理任务与报告，**不改动仓库首页等非任务文件**。

## 能力

| 能力 | 说明 | 依赖 |
|------|------|------|
| 创建 | 新增任务 / 父子任务，按项目分区，必填项缺失先追问 | 无 |
| 查看 | 按项目、状态、日期、父任务、归档和跨年范围筛选 | 无 |
| 修改 | 状态 / 时间 / 标题 / 备注 / 优先级 / 项目 / 结构调整 | 无 |
| 归档 / 恢复 | 显式触发在 `计划中` ↔ `已归档` 间移动，支持部分归档 | 无 |
| 报告 | 日 / 周 / 月 / 季度 / 半年 / 全年及任意日期工作总结 | 无 |
| 旧格式迁移 | 预检、备份并转换旧项目标签和备注 | 无 |

## 使用

```
$ai-obsidian:task-hub
```

或直接口令：

```
新增任务：接口联调，7月1日开始，7月10日完成，项目 支付
查看项目 支付 本周进行中的任务
完成：接口联调
重命名：支付 / 接口联调 → 支付接口联调
归档项目 支付 已完成任务
生成本周周报
生成 2026-07-01 到 2026-07-31 工作总结
```

## 依赖插件

周报使用 Sheets Basic 可渲染的标准 Markdown 三列表格，按 `^` 续行语义合并同一项目；不使用 AnyBlock、`[list2table]`、HTML `<table>` 或混排格式。周报默认只读取 `计划中.md`，避免归档副本造成重复统计。

## 旧数据兼容

`task-hub` 是唯一任务管理入口。读取时兼容旧 `#project/项目名` 和普通列表备注；普通修改保留原任务树格式。只有明确要求迁移时，才会在预览、备份和确认后统一为项目分区 + 行尾内联脚注格式。

接收 `session-scan` 结果时只处理已校验的 `session-scan/handoff/v1`；自由文本总结不能直接生成任务，日期为 `null` 时先询问，不猜测。
