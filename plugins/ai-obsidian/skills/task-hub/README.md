# task-hub — Obsidian 任务中枢

一个技能管起 Obsidian 任务的**完整生命周期**：创建、查看、修改、归档 / 恢复、格式迁移和生成报告。

## 设计：单一记录源

- **记录**：`任务/{YYYY}/计划中.md`、`已归档.md` —— 纯 Markdown checkbox，人可读可编、模型可读写。
- 创建 / 查看 / 修改 / 归档 / 报告使用同一套解析规则。
- **注释**：任务下方缩进 blockquote（`> ...`），与 checkbox 子任务区分；可选装 `任务样式.css` 片段做置灰 / 倾斜 / 浅背景。
- 只管理任务与报告，**不改动仓库首页等非任务文件**。

## 能力

| 能力 | 说明 | 依赖 |
|------|------|------|
| 创建 | 新增任务 / 父子任务，按项目分区，必填项缺失先追问 | 无 |
| 查看 | 按项目、状态、日期、父任务、归档和跨年范围筛选 | 无 |
| 修改 | 状态 / 时间 / 标题 / 备注 / 优先级 / 项目 / 结构调整 | 无 |
| 归档 / 恢复 | 显式触发在 `计划中` ↔ `已归档` 间移动，支持部分归档 | 无 |
| 报告 | 日 / 周 / 月 / 季度 / 半年 / 全年及任意日期工作总结 | 无 |
| 旧格式迁移 | 预检、备份并转换旧项目标签和备注 | 无 |

## 使用

```
/ai-obsidian:task-hub
```

或直接口令：

```
新增任务：接口联调，7月1日开始，7月10日完成，项目 支付
查看项目 支付 本周进行中的任务
完成：接口联调
重命名：支付 / 接口联调 → 支付接口联调
归档项目 支付 已完成任务
生成本周周报
生成 2026-07-01 到 2026-07-31 工作总结
```

## 依赖插件

**无。** 全部操作（创建 / 修改 / 归档 / 报告）纯 Markdown + HTML。周报表格用纯 HTML `<table>` + `rowspan`，项目列跨行合并由 Obsidian 阅读视图 / GitHub 原生渲染，不再依赖 AnyBlock。

## 旧数据兼容

`task-hub` 是唯一任务管理入口。读取时兼容旧 `#project/项目名` 和普通列表备注；普通修改保留原任务树格式。只有明确要求迁移时，才会在预览、备份和确认后统一为项目分区 + blockquote 格式。
